# Tidepool-monitoring
Seasonal monitoring of species composition in a fixed intertidal pool.

## About
This project documents seasonal changes in species composition within a fixed intertidal pool.
The aim is to build a long-term dataset of species observations through repeated photogrpahic monitoring.

## Monitoring site
One fixed intertidal pool is monitored at regular intervals. (location to be decided)
## Monitoring frequency
approximately once per month

## Data collected
- Date and time
- Tide state
- Weather conditions
- Water temperature
- Species observed
- Relative abundance
- Photographs
- Field observations
  
## Project status
ongoing
