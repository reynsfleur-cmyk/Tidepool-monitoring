# Tide Pool Monitoring Protocol

## Objective

To document seasonal changes in species composition within one
fixed intertidal pool through repeated observations and photography.

## Study site

One fixed intertidal pool is monitored throughout the study period.

The exact location is recorded using GPS coordinates and photographs.

## Monitoring frequency

The site is visited approximately once per month.

The same site is monitored during each visit.

## Data recorded

For each visit:

1. Date and time
2. Tide state
3. Weather conditions
4. Approximate water temperature
5. Overview photograph of the pool
6. Close-up photographs of observed taxa
7. Species/taxon list
8. Relative abundance
9. One-sentence observation compared with the previous visit
